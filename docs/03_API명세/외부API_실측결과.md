# TheSportsDB 무료 티어 실측 결과

| 항목 | 내용 |
|---|---|
| 측정일 | 2026-08-18 |
| 대상 | TheSportsDB V1 API, 무료 키 `123` |
| 리그 | Korean KBO League (`idLeague = 4830`) |

## 1. 엔드포인트별 실측

| 엔드포인트 | 파라미터 | 결과 | 판정 |
|---|---|---|---|
| `search_all_teams.php` | `l=Korean KBO League` | **10개 구단 전부 반환** | 사용 가능 |
| `lookup_all_teams.php` | `id=4830` | 잉글랜드 축구팀 24개 반환 (KBO 아님) | **사용 불가** |
| `eventsseason.php` | `id=4830&s=2026` | **15건만 반환** (2026-03-12 ~ 03-14) | 무료 한도 |
| `eventspastleague.php` | `id=4830` | 1건 | 무료 한도 |
| `eventsnextleague.php` | `id=4830` | 1건 | 무료 한도 |
| `lookuptable.php` | `l=4830&s=2026` | 0건 (KBO 순위표 없음) | 미제공 |
| `eventsday.php` | `d=...&l=Korean KBO League` | 0건 + Message | 프리미엄 추정 |

## 2. 핵심 결론

**데이터가 부족한 것이 아니라 무료 티어가 반환 건수를 제한한다.** 세 시즌을 교차 확인한 결과가 근거다.

| 시즌 | 반환 건수 | 날짜 범위 | 날짜별 경기 수 | 스코어 보유 |
|---|---|---|---|---|
| 2026 | 15 | 2026-03-12 ~ 03-14 | 5 / 5 / 5 | 0 / 15 |
| 2025 | 15 | 2025-03-08 ~ 03-10 | 5 / 5 / 5 | **15 / 15** |
| 2024 | 15 | 2024-03-09 ~ 03-11 | 5 / 5 / 5 | **15 / 15** |

세 시즌 모두 정확히 15건이며 전부 시즌 첫 3일치다. 날짜 순 정렬 후 15건에서 절단하는 구조로 판단된다. 하루 5경기가 빠짐없이 반환되므로 **KBO 일정 커버리지는 완전하며**, 2025·2024 시즌은 스코어도 모두 채워져 있어 **데이터 품질에도 문제가 없다**.

즉 무료 티어로 시즌 전체를 확보할 수 없는 것은 데이터 부재가 아니라 요금제 제한이다. 유료 구독 시 `eventsseason` 한도가 3000건으로 확대되어 시즌 약 720경기를 일괄 확보할 수 있다.

| 데이터 | 무료 티어 | 판단 |
|---|---|---|
| 구단 10개 | **확보 가능** | 1회 호출로 완료 |
| 구장 정보 | **확보 가능** | 팀 정보의 `strStadium`에 포함 |
| 시즌 경기 일정 | 15건 한정 (데이터는 완전) | **요금제 제한** |
| 경기 결과 | 1건 한정 (데이터는 완전) | **요금제 제한** |
| 순위표 | 미제공 | 자체 산출로 대체 (REQ-F-104) |

## 3. 데이터 품질 (확보된 범위)

경기 데이터의 스키마 자체는 충분하다. 실측 응답 예시는 다음과 같다.

| 필드 | 값 | 매핑 대상 |
|---|---|---|
| `idEvent` | `2400473` | `games.external_ref` |
| `dateEvent` | `2026-08-16` | `games.game_date` |
| `strTimestamp` | `2026-08-16T10:00:00` | `games.start_at` (UTC → KST 변환 필요) |
| `intHomeScore` / `intAwayScore` | `2` / `1` | `games.home_score` / `away_score` |
| `idHomeTeam` / `idAwayTeam` | `139824` / `139822` | `teams` 매핑 테이블 필요 |
| `strVenue` | `Gwangju-Kia Champions Field` | `games.stadium_id` |
| `strStatus` | `FT` | `games.status` = FINISHED |
| `strPostponed` | `no` | 우천 순연 판별 |
| `strSeason` | `2026` | `games.season_year` |

구단 목록도 정확하다.

| idTeam | 구단 | 홈구장 |
|---|---|---|
| 139819 | NC Dinos | Changwon NC Park |
| 139820 | LG Twins | Jamsil Baseball Stadium |
| 139821 | Lotte Giants | Sajik Baseball Stadium |
| 139822 | Doosan Bears | Jamsil Baseball Stadium |
| 139823 | Kiwoom Heroes | Gocheok Sky Dome |
| 139824 | Kia Tigers | Gwangju-Kia Champions Field |
| 139825 | Samsung Lions | Daegu Samsung Lions Park |
| 139826 | Hanwha Eagles | Daejeon Hanbat Baseball Stadium |
| 139827 | KT Wiz | Suwon Baseball Stadium |
| 139828 | SSG Landers | Incheon SSG Landers Field |

**설계 검증**: LG 트윈스와 두산 베어스가 잠실야구장을 공유한다. 구장과 팀을 별도 테이블로 분리하고 `teams.home_stadium_id`로 참조하도록 한 설계가 이 구조를 그대로 수용한다.

**주의 1**: 팀명과 구장명이 영문이다. 한글 표기는 자체 매핑 테이블로 관리해야 한다.

**주의 2 — 데이터 공백 가능성**: 2026 시즌 3월 경기 15건은 스코어가 모두 비어 있는 반면, 2025·2024 시즌 동일 구간은 모두 채워져 있다. 2026-08-16 경기는 스코어가 존재하므로 시즌 초반 일부 구간이 미기입된 것으로 보인다. 720경기 중 15건만 확인한 표본이므로 단정할 수는 없다.

**이 관찰은 사용자 제보 구조(REQ-F-606 ~ 608)의 근거가 된다.** 외부 API에 공백이 발생할 수 있음이 실측으로 확인되었으므로, 제보로 보완하는 이중 출처 설계가 필요하다.

## 4. 설계에 미치는 영향

| 영향 | 내용 |
|---|---|
| 사용자 제보의 근거 확보 | 외부 API에 스코어 공백이 실제로 관찰되었으므로, 이중 출처 구조가 가정이 아닌 측정 결과에 기반한 설계가 된다 (REQ-F-606 ~ 608) |
| 무료 단계의 경기 데이터 | 사용자 제보와 자체 시드 데이터로 확보한다 |
| 팀·구장 시드 | 외부 API 1회 호출로 확보. 영문명 → 한글명 매핑 테이블 필요 |
| 시즌 일정 | 개발·시연 단계는 자체 생성 시드 데이터로 대체. 실제 운영 시 유료 구독 필요 |
| 순위표 | 외부에서 가져올 수 없으므로 자체 산출이 유일한 방법임이 확인됨 (REQ-F-104) |
| `lookup_all_teams` 사용 금지 | 리그 ID로 조회 시 다른 리그가 반환되므로 `search_all_teams`를 사용한다 |
