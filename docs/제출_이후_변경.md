# 발표 자료 수정 (미제출)

13장을 처음부터 훑어 사실과 다른 다섯 건을 찾았다.

## 1. 테이블 표에 삭제한 테이블이 남아 있었다

8장 오른쪽 표에 `auth_tokens` 와 `game_result_reports` 가 있었다.
둘 다 V8 · V9 마이그레이션에서 지운 테이블이다. 여덟 개는 아예 빠져 있어
표에 20개만 있었고 옆 장의 「테이블 27」 과 맞지 않았다.

9장에서 「경기 결과는 운영자만 등록 · 정정한다」 고 말하는데 앞 장에 사용자 제보
테이블이 살아 있으면, 설계를 바꾼 사실 자체가 전달되지 않는다.

손으로 적어 두던 것을 `schema.dbml` 의 `TableGroup` 에서 읽도록 바꿨다.

## 2. 없는 요구사항 번호를 말했다

6장에 「REQ-F-606~608 을 추가했다」 고 적혀 있었으나 요구사항은 **REQ-F-606 까지**다.
「미확정 결과 표시(REQ-F-606)를 추가했다」 로 고쳤다.

## 3. 기술서 쪽수가 54 였다

5장 「산출물」 의 쪽수가 낡아 있었다. 제출본은 74쪽이다.
숫자를 적는 대신 만들어진 PDF 에서 읽도록 바꿨다.

## 4. 같은 장에서 정원 숫자가 달랐다

11장 왼쪽은 「정원이 3명인데」, 오른쪽 검증 출력은 「정원 4명(작성자 포함)」 이었다.
왼쪽을 「정원이 정해져 있는데」 로 바꿔 숫자를 한 곳에서만 말하게 했다.

## 5. 소셜 로그인의 한계를 적지 않았다

12장 제목이 「설계대로 구현하여 동작을 확인했다」 인데 검증 항목에
「소셜 로그인 — 3개 제공자 인가 URL 생성」 이 있었다. 로그인이 된다고 읽힌다.
제공자 키를 받지 못해 거기까지이며 `user_social_accounts` 는 0행이다.
「(키 미발급으로 여기까지)」 를 덧붙였다.
