# 프런트 디자인 시안 — 세 벌을 만들어 고른다

방향을 하나로 정하지 못했으므로 **세 벌을 다 만들어 놓고 눈으로 고른다.**

## 만드는 법

앱을 건드리지 않는다. `frontend/src/views/DesignLabView.vue` 한 화면에 세 벌을
나란히 그리고 `/design` 으로 연다. 고른 뒤에 그 한 벌을 앱 전체에 입힌다.

각 시안은 **같은 화면 조각 다섯 개**를 그린다. 이것만 보면 나머지가 어떻게 될지 안다.

1. 홈 상단 — 전적 요약 카드 (12경기 7승 1무 4패 · 승률 .636)
2. 경기 카드 한 줄 — LG 5 : 3 KT · 잠실 · 승 배지
3. 입력 한 벌 — 좌석 구역 고르기 + 별점
4. 구역 만족도 목록 — 표본 부족 표기 포함
5. 하단 탭 (모바일)

## 시안 A — 티켓 · 기록 (종이 · 아카이브)

로고가 티켓이고 직관 카드도 티켓 모양이다. 가장 어긋남이 적다.

| | |
|---|---|
| 바탕 | `#f7f5f0` 미색 종이. 카드는 흰색에 아주 옅은 그림자 |
| 잉크 | `#16355c` 네이비. 보조는 `#8a94a6` |
| 강조 | `#c0392b` 도장 빨강 — 결과 배지에만 |
| 모서리 | 4px. 각지게 |
| 결 | 절취선(점선), 카드 좌우 홈, 표는 장부처럼 괘선 정렬 |
| 글자 | 숫자를 크게. 승률 `.636` 은 소수점 앞을 지운 야구 표기 그대로 |

**승부처** — 결과 배지를 도장처럼 살짝 기울여 찍는다. 티켓에 도장이 찍힌 느낌.

## 시안 B — 야구장의 밤 (어둡고 조명)

| | |
|---|---|
| 바탕 | `#0d1117` 밤하늘. 카드는 `#161b22` |
| 조명 | `#f5a623` 야간 조명색. 강조와 별점에 |
| 잉크 | `#e6edf3` 흰 글자. 보조는 `#7d8590` |
| 모서리 | 12px. 둥글게 |
| 결 | 카드 위쪽에 조명이 떨어지는 그라데이션. 구장 사진을 어둡게 깔기 |
| 글자 | 숫자에 옅은 발광 |

**승부처** — 홈 화면 상단에 조명 켜진 야구장. 여기서 three.js 가 산다(아래).

**약점** — 전적표 · 구역 목록처럼 읽어야 하는 화면이 많고 낮에도 쓴다.
만들어 보고 실제로 읽히는지 본다.

## 시안 C — 스포츠 앱 (선명하고 빠릿함)

| | |
|---|---|
| 바탕 | `#ffffff`. 구역 나눔은 `#f1f3f5` |
| 강조 | `#0b5fff` 선명한 파랑. 승은 파랑, 패는 `#e03131` |
| 잉크 | `#212529` / 보조 `#868e96` |
| 모서리 | 8px |
| 결 | 굵은 구분선 없음. 여백으로 나눈다. 배지는 알약 모양 |
| 글자 | 굵기 대비를 크게. 800 과 400 만 쓴다 |

**승부처** — 숫자가 즉시 읽힌다. 표가 많은 이 서비스에 실용적이다.

**약점** — 어느 서비스에나 있는 모양이라 "오늘의직관" 다움이 약하다.

# three.js 를 어디에 쓰나

**억지로 넣지 않는다.** 로딩만 느려지고 발표에서 설명할 것만 는다.
쓸 자리는 아래 하나뿐이고, 시안 B 를 고를 때만 값어치가 있다.

## 쓰는 자리 — 홈 상단 야구장 (시안 B 전용)

단순화한 야구장을 낮은 폴리곤으로 그리고 천천히 돈다. 조명 네 개.
**특정 구장을 흉내 내지 않는다.** 야구장 일반의 형태다.
사용자가 기록한 구장 수만큼 조명이 켜지게 하면 "다녀온 만큼 밝아진다" 가 된다.

- 크기 : 화면 폭 × 높이 200px. 그 이상은 값어치보다 무게가 크다
- 조작 : 없다. 자동으로 아주 천천히 돈다
- 성능 : `prefers-reduced-motion` 이면 정지 이미지로 갈음한다.
  모바일에서 프레임이 떨어지면 끈다

## 쓰지 않는 자리 — 구장 좌석 3D

"어느 자리가 좋은가" 가 핵심 기능이라 값어치는 크다. 그런데 **구장이 아홉 개다.**
하나만 만들어 돌려쓰면 실제 배치가 아니게 되고, 발표에서 "이건 실제 모양이 아닙니다"
를 설명하는 순간 값어치가 사라진다. 아홉 개를 다 만들 시간은 없다.

대신 **2D 좌석 배치도**를 그린다. 구역 만족도를 색으로 칠하면 3D 보다 읽기 쉽다.
이건 세 시안 모두에 넣는다.

# 순서

1. `DesignLabView.vue` 에 세 벌 × 조각 다섯 개를 그린다. 앱은 건드리지 않는다
2. `/design` 에서 셋을 나란히 보고 고른다
3. 고른 한 벌의 값을 `src/style.css` 에 CSS 변수로 옮긴다
4. 공통 컴포넌트를 그 위에 만든다 — `Button` `Card` `Field` `Chip` `Stars` `EmptyState`
5. 모바일부터 맞춘다 (900px 브레이크포인트 · 하단 탭 · 안전 영역 · 터치 44px)
6. 데모 다섯 화면부터 입힌다 — 기록 작성 → 전적 → 구장 상세 → 기록 상세 → 홈

3번까지 가면 되돌릴 수 없으니, 2번에서 확실히 고르고 넘어간다.
