# 오늘의직관 (today-jikgwan)

KBO 직관 기록 및 관람 정보 서비스 — 웹 서비스 개발 Mini Project 산출물

- 작성자: 이채목
- 작성일: 2026-08-18

## 한 줄 소개

직관은 다녀오면 티켓은 서랍에, 사진은 갤러리에, 기억은 흩어진다. 이 서비스는 그 기록을 한곳에 모아 **내가 간 경기만의 전적**이라는 새로운 데이터를 만들고, 그렇게 쌓인 데이터를 **처음 야구장에 가는 사람의 좌석 선택 정보**로 되돌려준다.

## 데이터 출처 정책

경기 데이터는 **이용이 허용된 출처로부터만** 확보한다.

경기 데이터는 **이용이 명시적으로 허용된 공식 API**에서만 취득한다. 웹 페이지 크롤링은 구현하지 않는다.

| 출처 | 가부 | 근거 |
|---|---|---|
| **TheSportsDB 공식 API** | **채택** | 약관이 공식 엔드포인트를 통한 데이터 복사·가공을 명시적으로 허용. Korean KBO League (ID 4830), 2012~2026 시즌 |
| KBO 홈페이지 | 불가 | 이용약관 제14조 차항 — 자동화 수집 및 타 플랫폼 연동 금지 |
| STATIZ | 불가 | 운영자 문의 (2026-08-18) — 크롤링 금지이며 개인 이용자에게 제공 가능한 API 없음 |
| KB리포트 / 포털 | 불가 | 크롤링 불가 |
| KBO 공식 API | 없음 | 미제공 |
| **기상청 단기예보 (공공데이터포털)** | **채택** | 무료, 자동승인. 공공누리 적용 — 날씨 기능에 사용. 대체 경로로 기상청 API허브 |

**이중 출처 구조** — 외부 API를 1차 출처로 쓰되, 누락되거나 값이 어긋나면 사용자 제보로 보완한다. 직관 기록을 쓰는 사용자는 그 경기 현장에 있었으므로 결과를 알기 때문이다. 동일 경기 제보가 기준 수 이상 일치하면 결과를 확정한다.

**본 프로젝트는 무료 티어로 진행한다.** 라이브스코어와 전용 프로덕션 키는 유료 구독($9/월) 항목이며 향후 고도화로 분류한다.

상세는 `docs/01_기술서/01_요구사항정의서.md` 7장 참조.
